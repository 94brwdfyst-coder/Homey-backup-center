Backup Center — Beta

Back up and compare your Homey configuration, then selectively restore changes you explicitly confirm.

Features include Standard and Advanced Flows, folders, zones, Logic variables, devices, supported device settings and installed app information. Save files locally or via WebDAV. Schedule automatic WebDAV backups with retries and failure notifications. Choose English or Nederlands in app settings.

This beta is not a replacement for Homey's full system backup and recovery. Radio pairings are not recreated. Start with small, deliberate restore tests.

Restore and push access use a Homey API Key. Saved API Keys and WebDAV passwords are excluded from exports. Other device settings and Flow arguments can contain sensitive data; keep complete backup files private.

Version 0.3.27 improves large-backup transfers, browser downloads, schedule retries and feedback. Actual behavior depends on your Homey, browser and phone notification settings.
