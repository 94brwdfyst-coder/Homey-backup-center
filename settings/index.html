1. Back-up ophalen

This backup includes Flows, folders, devices, supported device settings, zones, Logic variables and an app inventory. The Homey API Key, WebDAV passwords and the Logic variable ha_backup_token are excluded. Other device settings and Flow arguments may contain sensitive information.

Download file uses a save dialog or the share sheet where supported. Otherwise a file link stays available. Browser restrictions may require opening Homey Web in a regular browser or saving to WebDAV.

2. WebDAV-locaties

Je kunt meerdere doelen opslaan, bijvoorbeeld NAS, Nextcloud of een andere WebDAV-server. De doelmap moet al bestaan. WebDAV-wachtwoorden blijven in de appinstellingen op Homey en komen niet in de back-up terecht.

SMB / SFTP network backups

Configure a destination, test it, then select it in the “Create backup to network destination” Flow action. Use a Homey date/time trigger to schedule it. The destination folder must already exist.

Passwords stay in Homey app settings and are excluded from this app's backup exports and Flow tokens. SMB2 is for a trusted local network; this client does not provide SMB3 encryption. SFTP requires the server host-key fingerprint. SHA256 is recommended, but SHA1 fingerprints are also accepted. Use the fingerprint of the existing SSH/SFTP host key shown by your NAS/server; do not create a separate key for Backup Center.

Network destination

Only the share name, not smb://host/ or a folder path.

SFTP: enter the existing absolute remote folder, for example /home/user/homey-backups.

Copy the host-key fingerprint shown by your NAS/server. SHA256 is recommended; SHA1 is also supported. Do not invent or generate a new key for Backup Center.

Flow scheduling runs once per action. Use the completion/failure trigger cards for follow-up actions. The existing WebDAV schedule remains configured separately.

4. Schrijfrechten voor restore

For restore writes, save a Homey API Key. Earlier versions called this a Personal Access Token (PAT). Existing saved keys are kept.

Where do I create a Homey API Key?

Open Homey Web, select your Homey and go to Settings → API Keys → New API Key. Name it Backup Center and grant the permissions below. Copy the key when it is shown and paste it here; Homey only shows it once.

Required permissions for full selective restore: Logic, Devices, Zones, Flows and Apps (write access). Technical scopes: homey.logic, homey.device, homey.zone, homey.flow, homey.app.

The connection test checks authentication. It does not prove that every write permission is present.

5. Automatische back-up

On selected weekdays, the app starts around the chosen time (Europe/Amsterdam, checked every minute). A failed backup gets up to two retries, at least 15 minutes apart, including after midnight. Manual backups have their own status. Only after all three attempts fail does the app send a push and create a Timeline notification.

The default recipient is this Homey's owner. Push requires a working Homey API Key with Flow write access; recipient lookup uses the app's Homey access. A critical push is used if available, otherwise a normal push. Phone notification settings still apply. Delivery errors appear below.
