Keep a copy of your configuration before making changes, so you can compare it later and selectively restore the changes you choose. Save your backups on your phone or computer, or send them to your own network storage. Automate backups and keep control of where your files are stored. Choose English or Dutch in the app settings.

Backups cover Flows, zones, Logic variables and supported device settings, alongside device and installed app information. This is a configuration backup, not a full system recovery: radio pairings are not recreated. Restore requires a Homey API Key. Saved API Keys and destination passwords are excluded from exports, but other settings and Flow arguments may contain sensitive data, so keep your backup files private.
